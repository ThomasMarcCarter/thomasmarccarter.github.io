## Overview

A personal portfolio to showcase web development projects. Projects are written as Markdown files in a content collection, so adding a new one is just adding a file.

## What I focused on

- Performance: static HTML with zero JavaScript by default
- Accessibility: semantic markup, keyboard navigation, skip link
- Dark mode that respects the system setting
