## Overview

A personal portfolio to show my web development work. Each project is a Markdown file, so adding a new one means adding a single file.

## What I focused on

- Performance: static HTML, with JavaScript only for the theme switch
- Accessibility: semantic markup, keyboard navigation and a skip link
- A light and dark theme that follows your system setting
